# Tracking-map-conditioned forecasting

AtlasTailor-T decomposes a later state into lineage transport of an individualized early state plus a source-learned temporal molecular correction. The public wrapper requires a compatible serialized tracking bundle. Unsupported genes retain the transported early state.

This is tracking-map-conditioned forecasting. It is not an autonomous developmental simulator and does not imply independent longitudinal molecular imaging. Later target expression is not an input to `forecast`.
