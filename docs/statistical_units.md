# Statistical and biological units

The appropriate unit depends on the experiment. Spots, cells, genes, directions, and sections are not automatically independent biological replicates.

| Experiment | Primary biological/generalization unit | Technical units |
|---|---|---|
| Zebrafish reciprocal reconstruction | embryo or directional target construction, as specified | cells, genes, seeds, reciprocal directions |
| MAP-T | embryo fold and lineage family | cells, genes, tracks, seeds |
| Human DLPFC | donor and adjacent-section pair | directions, spots, genes |
| SPATCH | specimen evaluation | bins, genes, technologies within specimen |
| Stroke | one sham-source/one stroke-target construction | sections, spots, genes |
| MASLD | patient; biopsies reported separately | spots and genes |
| PSC | one patient; four sections reported descriptively | sections, spots, genes |
| Alcohol-associated hepatitis | patient | spots and genes |

Bootstrap and aggregation procedures must follow the units encoded by each frozen analysis. Gene-wise distributions characterize the evaluation universe; they do not increase biological sample size.
