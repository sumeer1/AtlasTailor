# Release and Zenodo

1. Replace manuscript author placeholders and add the final manuscript/archival DOI.
2. Confirm author order, ORCIDs, software copyright ownership and dataset licenses.
3. Run the complete release-readiness checklist and archive its output.
4. Tag an immutable GitHub release only after the reusable and reproducibility repositories agree on the commit and manifest.
5. Enable the selected GitHub repository in Zenodo, create the tagged GitHub release, and let Zenodo archive that tag.
6. Add the resulting DOI to `CITATION.cff`, `.zenodo.json`, the reproducibility manifest and manuscript Code availability statement.

No DOI is assigned or implied by this release candidate.
