# Manuscript evidence architecture

The manuscript is framed as sparse adaptation of an external molecular atlas, rather than ordinary imputation within a partially observed sample.

## Evidence flow

1. **Framework and information boundary:** geometry-only atlas transfer followed by sparse target adaptation.
2. **Reciprocal reconstruction:** three developmental settings and both embryo directions.
3. **Residual inferential object:** atlas-relative deviations exceed tested technical nulls, align with developmental organization, and are recoverable.
4. **Tracking-conditioned forecasting:** an individualized early state is transported and corrected toward a later state.
5. **Generalization:** external 2D human tissue and cross-platform serial-section transfer.
6. **Pathological states:** stroke and multiple liver diseases, including target-withheld disease-gene examples.

The manual composition of these results into final Figures 1–6 is outside this repository. The companion [reproducibility repository](https://github.com/sumeer1/HyperSpatial-MAP-reproducibility) provides the bridge from each final panel to its generated source asset and frozen data.
