# Figure provenance

Every manuscript result is represented at three levels:

1. frozen numerical or spatial output;
2. independently generated source-panel SVG;
3. panel-level mapping to the final manuscript figure.

The final combined main figures are excluded because they were assembled manually in Inkscape. The software repository instead provides the final Figure 1 overview and compact frozen tables used by the published-results walkthroughs.

Use:

```bash
python scripts/verify_release.py
```

to validate the software-repository checksums.

The release does not claim that the final manual figure assemblies are generated by this package.
